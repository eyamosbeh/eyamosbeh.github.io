A vehicle marketplace with AI search

Mobile app, internship project, 2026.

A mobile marketplace where buyers search for vehicles, chat with sellers and ask an AI assistant for advice, while sellers publish listings, track how they perform and boost their visibility. I worked across the whole application, from authentication to the AI features.

A tour of the app

Tap a screen to see it larger.

The AI part: search by meaning, answers from real listings

This was the part I enjoyed most. Instead of matching keywords, the search understands what the user means, and the assistant answers using only the listings actually on the marketplace.

  1. A user asks a questionIn plain language, not keywords
  2. Semantic searchFinds the listings closest in meaning to the question
  3. Context is builtThose listings are added to the prompt
  4. Local modelQwen3 runs on the server through Ollama
  5. Grounded answerBased on real, available vehicles, with a match score for each

Semantic search

Finds vehicles from what a query means rather than the exact words used.

"a reliable family car for city driving"

RAG assistant

Retrieves the relevant listings first, so replies stay tied to what is actually for sale.

Runs locally

Qwen3 through Ollama keeps the model on our own infrastructure, with no external AI API.

Boost plans

Testing and hardening
